===================================================
  Teacher Assistant - Quick Start Guide
===================================================

Option 1: Windows Installer (Recommended for Teachers)
---------------------------------------------------
1. Download and run "TeacherAssistant-Setup.exe".
2. Follow the setup wizard (no administrator rights needed).
3. Click the "Teacher Assistant" shortcut on your Desktop or Start Menu.
4. The application starts silently in the background and opens in your default browser.

Option 2: Portable Bundle (No Installation Needed)
---------------------------------------------------
1. Download and extract "TeacherAssistant-v1.0.0-Windows-Portable.zip".
2. Double-click "start-app-hidden.vbs" (silent background launch) or "start-app.bat".
3. The app will automatically configure itself and open in your browser.

Sharing on School Wi-Fi / Local Network
---------------------------------------------------
- Start Menu: Click "Teacher Assistant (Network Mode)".
- Portable bundle: Double-click "start-internal-site.bat".
- Other teachers / devices on the same Wi-Fi can open the URL displayed in the window (e.g., http://192.168.1.50:3000).

First-Time Login
---------------------------------------------------
- Default Username: admin
- Default Password: admin123

Important Security Note:
Please change the default admin password after your first login by navigating to:
Admin Dashboard -> Settings

Closing the Application
---------------------------------------------------
- Desktop / Start Menu: Double-click "Stop Teacher Assistant".
- Portable bundle: Double-click "stop-app.bat".
- If running visible "start-app.bat" or network mode, close the terminal window.
